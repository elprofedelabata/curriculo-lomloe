# ODT de apoyo para ESO de Canarias

La [Consejería de Educación de Canarias](https://www.gobiernodecanarias.org/educacion/web/secundaria/informacion/ordenacion-curriculo/curriculos-de-la-educacion-secundaria-obligatoria-eso/index.html) ofrece un ODT por cada una de las 23 materias de ESO y cada uno de los tres ámbitos de Diversificación Curricular. Los 26 archivos se conservan aquí para reconstruir la estructura de las tablas y listas. [`manifest.json`](manifest.json) indica el nombre, los cursos, el archivo local y el enlace institucional de cada uno.

Los JSON se han cotejado con los PDF del BOC, incluidos sus números locales de saberes. Las diferencias de redacción del ODT se ajustan al texto publicado mediante el extractor. La reorganización confirmada de los bloques 5 y 6 de Segunda Lengua Extranjera queda documentada como revisada en [el registro de Canarias](../../../../incidencias/es-cn.md).

**Los PDF del BOC son la fuente normativa:** [Decreto 30/2023](../../normativa/eso-bachillerato/2023-03-16-decreto-30-2023-curriculo-eso-bachillerato.pdf) para las materias y [Decreto 86/2025](../../normativa/eso/2025-06-30-decreto-86-2025-diversificacion-curricular.pdf) para los ámbitos de Diversificación. Los ODT se usan como ayuda de extracción y se cotejan con los PDF. Sus URL institucionales incluyen la palabra «borrador» en la ruta; eso no sustituye la publicación oficial.
