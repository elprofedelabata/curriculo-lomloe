# Documentos ODT de apoyo para Primaria de Canarias

La Consejería de Educación de Canarias ofrece estos ODT por áreas desde su [página de ordenación de Primaria](https://www.gobiernodecanarias.org/educacion/web/primaria/informacion/ordenacion/). Se conservan para que [`extract-es-cn-primaria.py`](../../../../scripts/extract-es-cn-primaria.py) pueda reconstruir las tablas y las listas. **La fuente normativa de los JSON es el [PDF del BOC del Decreto 211/2022](../../normativa/primaria/2022-11-10-decreto-211-2022-curriculo-primaria.pdf)**; el extractor coteja los criterios con él y corrige las divergencias detectadas en los ODT de apoyo.
